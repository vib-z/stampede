# Any machine: stampede on a remote computer (setup B)

No machine of your own needs to stay on. Everything runs on one remote computer: a Grok Bot or ChatGPT Dots computer, a rented server, or any Mac (Linux is untried: the event relay uses macOS tools). Herdr, the agent CLIs and stampede are installed there, and you watch from your phone or laptop. This guide is written for an agent to follow, step by step. Setup A, where a bot drives your own machine, is [grokbot/](../grokbot/README.md).

## Do
- Follow the parts in order; finish each one's check before the next.
  - [1-os.md](1-os.md): know the machine.
  - [2-herdr.md](2-herdr.md): install Herdr with its own guide.
  - [3-stampede.md](3-stampede.md): install stampede and its settings.
  - [4-agents.md](4-agents.md): the agent CLIs, sign-in and trust.
  - [5-watch.md](5-watch.md): how the person watches from elsewhere.
  - [6-verify.md](6-verify.md): prove it works.
- Ask the person before every install and every settings change.
- Never type a password, a code or a key for them; sign-ins are theirs.
- Link to each vendor's own steps; never copy them.
- Stop and report the first failure, with the exact output.

## Run
```text
Read <stampede>/remote/any-machine/README.md and set this machine up for stampede, part by part. Ask me before each install.
```

The owner gates hold here too: [README, Safety](../../README.md#safety). Every setting and its default: [config.example](../../config.example).
