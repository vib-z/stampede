# Product marks

The README's "Works with" section uses these marks to name the agents and tools stampede works with. The marks belong to their owners, who keep every right in them; their use here implies no endorsement, and the repository's MIT license does not cover them. Geometry is unchanged. A `-dark.svg` file is the owner's own version for dark grounds where one exists; otherwise only its single ink colour is set (black for light grounds, white for dark), because GitHub draws an `<img>` without the page's colour.
