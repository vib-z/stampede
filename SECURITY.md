# Security

Please report a security problem privately, not in a public issue: use **Report a vulnerability** on the repository's [Security tab](https://github.com/vib-z/stampede/security). Say what you found, how to reproduce it, and which version (`stampede --version`). You will get a reply within a week.

stampede runs agents on your machine. What it never does without your own tap, and how it keeps agents out of no-checks mode, is in the README's [Safety](README.md#safety) section. Never paste keys, tokens or `.env` contents into a report.
