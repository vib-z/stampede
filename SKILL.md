# stampede

Start at [USING.md](USING.md): the command that starts a job, the commands that follow, where the job folder is and the gates.

One ask, one lead, and a helper only when it pays. The lead plans in `plan.md`, works, and brings the owner only the questions and gates that are theirs. A bot, a chat outside Herdr or a Herdr pane can start the job.

- **Starting a job** (any chat the owner asks to use stampede): [skills/stampede/SKILL.md](skills/stampede/SKILL.md).

- **A bot front door** (outside Herdr, over SSH): [skills/grokbot-herdr/SKILL.md](skills/grokbot-herdr/SKILL.md).
